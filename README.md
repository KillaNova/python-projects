## Learning Projects

### `python_course.py`
Core Python fundamentals practice.

### `Python_getallen.py`
Number input and math with exception handling. (Dutch: *getallen* = numbers)

- Power calculator

### `Libraries.py`
Standard library exploration.
- `datetime` — get and print current date/time
- `os` — get the current working directory
- `json` — write and read a JSON profile file (`profiel.json`)

### `Python_API.py`
Live Bitcoin price fetcher using the Coinbase API.
- Fetches BTC/EUR spot price
- Error handling with `try/except`

### `project_BTC_API`
BTC price tracker with history logging.
- Fetches live BTC/EUR price from Coinbase
- Saves each result with a timestamp to `tracker.json`
- Reads and prints the saved history

### `food_macros_eu.db`
SQLite database containing European food macro data (calories, protein, carbs, fat).

## Automation Projects

### `duplicate_finder/`
Scans a directory for duplicate files using SHA-256 hashing and lets you remove them.

```bash
# Preview what would be deleted (safe)
python duplicate_finder/main.py C:\Users\gangs\Downloads --dry-run

# Auto-delete duplicates, keep the shortest path copy
python duplicate_finder/main.py C:\Users\gangs\Downloads --auto

# Interactive mode — choose which copy to keep
python duplicate_finder/main.py C:\Users\gangs\Downloads
```

**Dependencies:** none (stdlib only)

### `web_scraper/`
Scrapes prices, news headlines, and remote job listings.

```bash
pip install requests beautifulsoup4

# Top 20 Hacker News stories
python web_scraper/main.py news

# Remote Python jobs
python web_scraper/main.py jobs --keyword python

# Prices from any product page (give it a CSS selector)
python web_scraper/main.py prices --url https://books.toscrape.com --selector .price_color
```

**Dependencies:** `requests`, `beautifulsoup4`

### `email_autoresponder/`
Connects to your inbox via IMAP and auto-replies, moves, or labels emails based on rules.

**Setup:**
1. Copy `config.example.json` → `config.json`
2. Fill in your email + app password (Gmail: use an [App Password](https://myaccount.google.com/apppasswords))
3. Edit the rules in `config.json`

```bash
# See your rules
python email_autoresponder/main.py --list-rules

# Process inbox once
python email_autoresponder/main.py --run

# Keep checking every 60 seconds
python email_autoresponder/main.py --run --loop
```

**Supported rule actions:** `reply`, `move`, `label`  
**Dependencies:** none (stdlib only — `imaplib`, `smtplib`, `email`)

---

### `api_health_checker/`
Monitors API endpoints, checks status codes, measures response time, and alerts on failures.

**Setup:**
1. Rename `endpoints.example.json` → `endpoints.json`
2. Add your API endpoints

```bash
pip install requests

# One-shot health check
python api_health_checker/main.py --check

# Continuous monitoring (every 60s)
python api_health_checker/main.py --watch

# Check every 30 seconds
python api_health_checker/main.py --watch --interval 30

# Summary report from history
python api_health_checker/main.py --report
```

**Dependencies:** `requests`
