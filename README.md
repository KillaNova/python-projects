# Python Projects — KillaNova

Personal collection of Python scripts built while learning the language from the ground up.

---

## Projects

### `python_course.py`
Python fundamentals practice file.
- Variables, strings, booleans, lists
- Conditionals (`if / elif / else`)
- Loops (`for`, `range`)
- Functions with parameters

### `python_project_1`
Personal profile app — one of the first full scripts.
- Prints a profile to the console
- Writes and reads a profile to `profiel.txt`
- Uses **classes** and **OOP**: `person`, `persoon_1`, `my_religion`
- Demonstrates `__init__`, instance methods, and return values

### `Python_getallen.py`
Number input and math with error handling. *(Dutch: getallen = numbers)*
- Division with zero-division protection
- Power calculator
- `try / except` for `ValueError` and `ZeroDivisionError`

### `Libraries.py`
Standard library demos.
- `datetime` — current date and time
- `os` — working directory
- `json` — write and read a JSON file

### `Python_API.py`
Live Bitcoin price fetcher.
- Calls the Coinbase API for the BTC/EUR spot price
- Handles errors gracefully with `try/except`

### `project_BTC_API`
BTC price tracker with history logging.
- Fetches live BTC/EUR price
- Saves each result with a timestamp to `tracker.json`
- Reads and prints the saved history

### `food_macros_eu.db`
SQLite database with European food macro data (calories, protein, carbs, fat).

---

## Data Files

| File | Description |
|---|---|
| `profiel.json` | JSON profile generated by `Libraries.py` |
| `profiel.txt` | Text profile generated by `python_project_1` |
| `tracker.json` | BTC price history from `project_BTC_API` |

## How to Run

Make sure Python is installed, then run any script:

```bash
python python_course.py
python Python_getallen.py
python Libraries.py
python Python_API.py
python project_BTC_API
```

For the API scripts you need the `requests` library:

```bash
pip install requests
```
